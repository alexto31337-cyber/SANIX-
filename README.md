# Дашборд мониторинга ГТМ · Федоровское месторождение

Интерактивный дашборд для мониторинга фонда бездействующих скважин и анализа
эффективности геолого-технических мероприятий (ГТМ).

## Стек

- **React 18** + **Vite**
- **Tailwind CSS** — стилизация (тёмная тема)
- **Recharts** — графики
- **Lucide React** — иконки

## Возможности

- Сводные KPI-карточки (скважин в ремонте, прирост добычи, среднее пластовое давление)
- Линейный график динамики ГРП и КРС по месяцам
- Реестр скважин с фильтрацией по статусу (ГРП / КРС / Ожидание)

## Запуск

```bash
npm install
npm run dev
```

Затем открой адрес, который Vite выведет в консоль (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```
